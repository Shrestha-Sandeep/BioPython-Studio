# P03 — Microscope-field loops and collections

**Outcome:** process more than one recorded microscope field, apply a transparent rule and produce a compact quality-control summary. This chapter covers competencies **012–018**. It is the first cumulative multi-record workflow.

## 1. From one measurement to a collection

A list stores an ordered sequence of values. Python indexing starts at zero, so `scores[0]` is the first score, not the zeroth recorded field.

```python
focus_scores = [0.81, 0.63, 0.94, 0.70]
print(focus_scores[0])
print(focus_scores[-1])
print(focus_scores[1:3])
```

The last statement slices from index 1 up to but not including index 3. Predict which two values it returns. The negative index `-1` selects the last element, which is useful but fails for an empty list.

Lists can be changed with `append()` and assignment, but **mutation is not the same as making a new copy**. If two names refer to the same list, modifying either changes the shared object. For this course, prefer creating new collections when you need to preserve the original observations.

A tuple such as `(sample_id, score)` is an ordered, immutable pair. The assignment `sample_id, score = record` unpacks it. This is a small building block for structured experimental records.

## 2. A loop processes each observation

Repeating one statement by hand is error-prone. A `for` loop processes a list element by element.

```python
scores = [0.81, 0.63, 0.94, 0.70]
accepted = []
for score in scores:
    if score >= 0.70:
        accepted.append(score)
print(accepted)
```

Predict the resulting list and whether the input `scores` changes. The control flow is determined by indentation: `accepted.append(score)` occurs *inside* the conditional and the loop, while the final print occurs once.

A biological measurement can be recorded alongside a field ID. Once you have more than a single field, a pipeline must keep the identity and score together, not assume that a sorted or filtered list still aligns with the original metadata.

## 3. Keep a traceable field index

`enumerate(scores, start=1)` produces pairs such as `(1, 0.81)` and `(2, 0.63)`. The start argument can match field numbering used in a lab notebook without changing Python list indices.

```python
for field_number, score in enumerate(scores, start=1):
    print(field_number, score)
```

`range(n)` generates the integers 0 through n-1; it is best for a fixed number of repetitions. Use `enumerate()` when you need the observation and its index. Avoid manually tracking indices unless that genuinely improves the logic.

A `while` loop keeps running while a condition is true. Always ensure that its state changes in a bounded way; otherwise the code can loop indefinitely. The exercise asks for a controlled stopping rule, not an unbounded search.

## 4. Skipping and stopping are different decisions

`continue` skips the rest of the current iteration; `break` ends the loop. In data quality work, those choices carry scientific meaning. Skipping a missing focus value does **not** mean the field never existed. Record exclusions and reasons. Stopping an acquisition review early requires a specific documented rule; it should not silently drop later measurements.

```python
scores = [0.81, None, 0.94]
valid_scores = []
for score in scores:
    if score is None:
        continue
    valid_scores.append(score)
```

`None` signals missing data; it should not be replaced blindly with zero, because zero is a measurement and missingness is a different state. Later Pandas lessons add more rigorous handling.

## 5. Build a simple trustworthy summary

A useful miniature program accepts recorded field scores, identifies records that meet a stated threshold, counts the ones rejected and reports both numbers. It should behave correctly for an empty list, a boundary score, repeated values and missing fields. It must not divide by zero when no valid field exists.

Activities P03-A to P03-E separately teach indexing and tuple unpacking; list mutation; filtering with `for`/`if` and `continue`; field numbering with `enumerate()`; and safe bounded `while` loops. A final transfer changes both the number of fields and the cutoff.

## 6. From field QC toward microscopy

This chapter intentionally operates on **recorded scores**, not pixels. In I01 you will open an actual attributed microscopy image; later lessons will calculate quantities from arrays and trace them back to field IDs. Remember that several fields from the same worm, plate or biological sample are not automatically independent replicates. Aggregating them as if they were separate animals or cultures can create pseudoreplication.
